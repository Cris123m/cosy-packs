# cosy-packs — scene packs for Cosy Home

Independent designs loadable by the base launcher, one at a time.
Each pack = `pack.json` (+ optional `preview.png`).

- Spec: `PACK-SPEC.md` (v2: inline hills/ops/smoke/windows, no SVG file).
- Validate: `python3 tools/validate.py packs/quito`.
- Packs: `quito` (v2: El Panecillo silhouette + Virgen statue, valley palettes).
- Template: copy `packs/_template` to start a new city.
